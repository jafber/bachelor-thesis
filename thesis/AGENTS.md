# Typst Source Code

## File structure

Typst entry point is `main.typ`. Find source code for the chapters in `chapters/` (e.g. `chapters/intro/intro.typ` for the introduction) Figures go into their chapter's directory. Appendix is in `appendix/appendix.typ`.

## Typst syntax

*Typst is not LaTeX. Look up syntax before writing formulas!*

Find docs [here](https://typst.app/docs/reference/math/). 

Example of a valid formula:

```
$ op("CR")_"question-ablated" (i) = L(s_i | q, s_(<i)) - L(s_i | q_g, s_(<i)) $
```
