# Does the Question Support This Reasoning Step? Detecting Reasoning Errors with Contextual Calibration

This is the repository for my bachelor thesis at the chair for [Artificial Intelligence and Intelligent Systems](https://hpi.de/de-melo/home.html) of the [Hasso Plattner Institute](https://hpi.de).

Experiment notebooks are in [`experiments/notebooks/`](experiments/notebooks/). Open or run them with that directory as the working directory. To regenerate every data-driven thesis plot from existing SQLite caches, run all cells of [`experiments/generate-plots.ipynb`](experiments/generate-plots.ipynb) with `experiments/` as the working directory; outputs go to `thesis/figures/`.
